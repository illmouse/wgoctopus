Generate

Generates AmneziaWG obfuscation parameters that make the tunnel harder for DPI to recognise. Each setting carries a badge showing where it matters:

  • {{ scope("both") }} must be identical on the server and on every client (S1–S4, H1–H4, header key, random trailers). A mismatch silently drops packets.
  • {{ scope("client") }} is used by the sending side only (Jc/Jmin/Jmax, I1–I5, content padding). Give different clients different values; a junk train shared by everyone becomes a template of its own.
  • {{ scope("local") }} affects this side only (timers, cookies).

The defaults are a sensible starting point. If a network blocks you, change one thing at a time and climb to the next AWG version only when the current one is blocked.

The generation algorithms and parameter descriptions are adapted from Any-Tech-ARCHITECT by VAI_PROG (Vadim), MIT License. Thank you for the great work.

Packet padding (S1–S4)

Random bytes added in front of each packet type: S1 initiation (base 148 bytes), S2 response (92), S3 cookie reply (64), S4 data (32). Leave all empty and the generator picks collision-free values.

Fixed S sizes (optional){{ scope("both") }}
{% for n, what in [(1, "initiation"), (2, "response"), (3, "cookie reply"), (4, "data")] %}
{% endfor %}
Set values by hand only to match an existing peer. The resulting sizes (148+S1, 92+S2, 64+S3, 32+S4) must all differ, otherwise the fingerprint comes back. Large S1–S3 exceed the IPv6 minimum MTU and get fragmented. S4 is added to every data packet, so keep it at 32 or less to protect speed. With header protection every S must be at least 12.

Message headers (H1–H4)

The WireGuard message types 1–4 are replaced with random ranges that must not overlap each other or hit 1–4.

{{ gswitch("narrow_h", "Narrow H ranges", "both", "2.0+", "Makes the ranges narrower (about 1k–10k wide instead of up to 50k). Mimicry (I1–I5)

Fake packets sent before the handshake so the first packets look like another protocol. The receiver ignores them. Pick what looks ordinary in the network you connect from.
